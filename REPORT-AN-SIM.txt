EACH SCENARIO (inputs, engine result checked)
====================================================================
Each scenario is a change to the imagined year, run through the EXISTING
engine (dossier.simulationResults, shared with the forecast, R281/R206) and
shown against the current projection. The controller parses the raw inputs;
an empty or invalid field is a no-op (the simulated figure equals the
baseline), never a crash. Figures are from the engine, never the UI (R340).

  ONE MORE DAY AT HOME EACH WEEK (EXTRA_WEEKDAY). The person picks a weekday
    that is not already a home day. SimChange.ExtraWeekday(day). The design's
    own example (70 recorded, Domicile Tue/Thu, adding Friday from 9 Oct
    2026) is the simExtraWeekday baseline: 39,16 % -> 43,75 %, 9 days over
    the fiscal ceiling, 14,5 before social - the engine's numbers, matching
    the design's sample figures.
  EXTRA TELEWORK DAYS THIS MONTH (EXTRA_MONTH_DAYS). A number.
    SimChange.ExtraMonthDays(n>=0).
  A DIFFERENT EMPLOYMENT RATE (RATE). A number 1..100, seeded to the current
    rate so nothing changes until it is edited. SimChange.Rate; the engine
    applies R290's basis change - REUSED, never a second copy (R206).
  MISSIONS (MISSIONS). A count in France and a count in a third state.
    SimChange.Missions(france, third); the engine applies the 10-day limit,
    its proration and its order (France first) exactly as for the record.
The unit witness SimulationR340Test runs all four changes and asserts the
engine produces a result and the recorded list is returned unchanged.
