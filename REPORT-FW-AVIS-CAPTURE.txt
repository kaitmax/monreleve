DEFECTS
====================================================================
- DEFECT 1: a filtered regeneration by spec path does not run.
  - What runs: `pnpm test:visual:update -- <spec>`, which reaches
    Playwright as `--update-snapshots <spec>`.
  - Playwright 1.63's `-u, --update-snapshots [mode]` takes an optional
    VALUE, so it consumes the spec as the mode and exits:
      error: option '-u, --update-snapshots [mode]' argument
      'e2e/calculateur.visual.spec.ts' is invalid. Allowed choices are
      all, changed, missing, none.
  - tests/unit/meta/visual-filter.test.ts ("keeps a filtered regeneration
    a regeneration of only what was named") asserts exactly that argv,
    ['--update-snapshots', 'e2e/calculateur.visual.spec.ts']. The unit
    test is green; the command it certifies cannot run.
  - The `--grep` form works, because `--grep` starts with a dash.
  - Not touched: scripts/visual.mjs and its tests are off-limits to this
    session (PARALLEL MODE rule 4).
  - A candidate fix is to emit `--update-snapshots=changed`, with the test
    asserting it. It needs a positive test that the container run accepts
    it (R154).
