1. THE BUG
--------------------------------------------------------------------------------
Fr.kt line 12 held  const val GREETING = "Bonjour Camille"  and
AujourdhuiScreen.kt line 127 rendered it verbatim (Text(text = Fr.GREETING, ...)).
The greeting was a fixed placeholder that never read the signed-in account's name.
Found by the device-walkthroughs pass: a fresh account named "Walkthrough" (the DB
row wt-fresh and the onboarding "Tout est pret" summary both showed "Walkthrough")
was still greeted "Bonjour Camille". AN-ONBOARD already stores the holder name in
Settings.name (set via /api/v1/me); the screen simply ignored it.

--------------------------------------------------------------------------------
2. THE FIX
--------------------------------------------------------------------------------
- Fr.greeting(holderName: String?) is a pure, JVM-testable function in fr/. It
  greets the holder's FIRST name and falls back to "Bonjour" alone when there is
  no name. First name = the first whitespace-delimited token after trimming; a
  hyphenated first name ("Jean-Pierre") is kept whole. The "Bonjour" prefix and
  the template are the only literals and they live in fr/ (Fence 4: no literal in
  a composable; R153/R181: the name is interpolated DATA, never a hard-coded
  person).
- AujourdhuiState gained  holderName: String? = null  (defaulted; every call site
  uses named args, so nothing positional broke).
- AujourdhuiController sets holderName = settings?.name in BOTH the initial
  MutableStateFlow value and the emitState() copy, so the first emission and every
  refresh carry the name. settings is the controller's already-loaded
  settingsStore.load().
- AujourdhuiScreen.Header(today, holderName) reads state.holderName and renders
  Fr.greeting(holderName). Fr.GREETING is removed.

COPY DECISION (operator decision, taken under R156 - the advisor stalled all
session and the task authorised a conservative, recorded choice):
  * FIRST name, not full name. The historical "Bonjour Camille" is the first name
    of "Camille Martin", so greeting by the first name preserves the intended
    render while now reading real data.
  * FALLBACK for a not-yet-named account = "Bonjour" alone (no stray or blank
    name, no crash). A canton-without-a-name account (the AN-ONBOARD-2 partial
    case) can reach Aujourd'hui, so the null/blank path is a real one.
