PRECONDITIONS, AND THE FIRST FINDING
--------------------------------------------------------------------
R1's gate:clone FAILED on f9521aa - origin/main's HEAD, a tree nobody
had modified - and PASSED on a re-run of the same commit. Two runs,
one commit, opposite results.

THE MECHANISM, REPRODUCED IN ONE COMMAND:

  pnpm exec vitest run tests/unit/pages/accessibility-faq.test.tsx \
    --testTimeout=600

  test 1  Error: Test timed out in 600ms.
  test 2  Unknown Error: Axe is already running.

Byte for byte the clone's failure. A healthy axe run over that page
costs about 1,15 s against vitest's 5 s default, so a machine 4x
slower exceeds it - and a fresh clone installing into a temp directory
demonstrably is.

WHAT MAKES IT WORSE THAN AN ORDINARY SLOW TEST: axe holds a GLOBAL
lock. When vitest abandons a timed-out test the run keeps going and
keeps the lock, so every later axe call in that file fails. ONE slow
test becomes N failures, and the log names the LOCK rather than the
TIMEOUT - which reads like a concurrency bug in the tests instead of a
machine under load.

TWO CORRECTIONS TO THE RULINGS AS GIVEN, both from measurement:

  FILE PARALLELISM IS NOT THE CAUSE. With isolate: true each file has
  its own module registry, so two files cannot share axe's lock. Those
  two tests were ALREADY serial. Running the a11y specs single-file
  would have fixed nothing.

  THE CLONE ALREADY INHERITED R99's WORKER CAP. maxWorkers lives in
  vitest.config.ts and applies to every run. There was no full-width
  default to correct; what was missing was the ENVELOPE, never printed.

SO THE FIX IS THE BUDGET: testTimeout 20 s, ~17x the measured cost.
And gate:clone now states cpus, the inherited cap and free memory.

  IT EARNED ITS KEEP ON THE FIRST RUN: 716 MiB free of 16195. That is
  the number that answers "did the code break or did the machine?",
  and it was not in the log before.

  AND THE FIX WAS THEN TESTED BY ACCIDENT UNDER THE SAME PRESSURE.
  The next clone ran at 716 MiB free and passed, with zero axe
  incidents. Same condition, opposite result.

INCREMENT 1 - THE CSV
--------------------------------------------------------------------
GET /api/v1/export/csv?year=. SPEC 12's eleven columns verbatim, held
by a snapshot IN the test so a reviewer sees the contract rather than
a hash.

THE DATE FORMAT IS ISO, AND THE FAILURE IT AVOIDS IS NOT THE OBVIOUS
ONE. Excel showing 2026-07-07 as a date is a display transformation
the day survives. What must never happen is an AMBIGUOUS form:
03/04/2026 is a different day in Paris and in New York, and a dossier
that means two things depending on who opens it is worse than one that
is hard to read. ISO also sorts chronologically AS TEXT.

  It does NOT force Excel to treat the column as text. The two ways to
  do that - a leading apostrophe, or ="2026-07-07" - both corrupt the
  file for every other reader, and the second writes a formula to
  prevent a formula.

A TEST THAT FAILED FOR A REASON WORTH KEEPING. The BOM assertion used
response.text() and failed: the WHATWG UTF-8 decoder STRIPS a leading
BOM, so text() can neither confirm nor deny one - and the inverse
assertion would "prove" it absent on a file that has it. It is now
asserted on the bytes: [0xEF, 0xBB, 0xBF].

R175: the CSV and the annex carry the SAME day set, asserted, because
they bound one property from opposite sides. The CSV IS the annex
serialised differently rather than a second query.

QUOTING TESTED CASE BY CASE - comma, embedded quote, newline, and
SEMICOLON, which RFC 4180 does not require but European Excel locales
need. The newline case asserts the RECORD COUNT, since a note becoming
two rows is invisible to a contains check. An ordinary note is
asserted UNQUOTED, or a writer that quoted everything would pass all
of them.

INCREMENT 2 - THE PRINT ROUTE
--------------------------------------------------------------------
/releve/print?year=&token=. The first surface that renders the FW24
payload.

THE TOKEN IS SHORT-LIVED, NOT SINGLE-USE, AND THE REASON IS A RULE.
Single-use needs server state to record consumption: a row, a model, a
schema change - ASK-FIRST, and not sought. AC3 permits either.

  What 120 seconds costs: a token captured from an access log within
  two minutes can replay that ONE year for that ONE person. No other
  year, no other account, no write, no bearer privileges.

  IT IS IN A URL BECAUSE A PERSON HAS TO OPEN THE DOCUMENT. Increment
  4 requires a human to read it, and a browser sends no Authorization
  header for a typed URL. A requirement, not a limitation.

  THE GRANT IS (PERSON, YEAR). R198: missing, invalid, expired,
  wrong_year and not_configured are five facts with five names.

AUTH_SECRET WAS ANTICIPATED AND NEVER INTRODUCED - it appeared only in
gate:clone's scrub list. The code REFUSES an unset secret and REFUSES
the placeholder .env.example ships, by value. R205 applied to a key: a
route that signs with a default is worse than one that refuses.
