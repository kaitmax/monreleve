ITEM 4 - WORKTREE OWNERSHIP (R392)
--------------------------------------------------------------------------------
Written into CLAUDE.md immediately after the R349 worktree clause it extends.
R349 says what a session does in ITS OWN worktree; R392 is the same clause read
from the other session's side.

THE TEXT IT EXTENDS, quoted as R392 requires:

  R334: "A session never deletes, overwrites or resets anything it did not
  create. ... an untracked or unexpected file is REPORTED, never removed; every
  agent works in its OWN git worktree; nothing destructive - checkout -f, reset
  --hard, clean, rm - runs in a directory another agent may be using".

  R349: "every session runs in its OWN git worktree ... A session also writes a
  lock file carrying its identity into that worktree, and refuses to run git in
  any worktree holding another session's lock, or carrying staged or
  uncommitted changes it did not make. Finding another session's work, it stops
  and reports ... a lock, not ListAgents, is what says a session is running."

THE NEW CLAUSES: commit only in your own worktree; never commit, stash, reset
or remove in a worktree whose lock you did not create; never remove a worktree
with uncommitted changes or unpushed commits, whoever owns it; branch and
remote-ref deletion after a merge only once the owning session's report is on
main, or the operator says so.

WHAT IT COST. A session took KMP-1's uncommitted work from a live worktree,
committed it as 800549d, merged it, deleted the branch and both remote refs,
and removed C:/wt/kmp-1 - while the owning session's :app:gate was running in
that directory. The gate reported "./gradlew: No such file or directory", which
is NO RESULT, and was nearly read as one. Nothing was lost; nothing about that
was guaranteed.

IT IS NOT MECHANICAL. There is no merge/cleanup script in this repository -
searches for `worktree remove` and `worktree prune` return nothing - so the
removal was by hand or by an agent's own command. R392 therefore has the
standing R334 had before R349 gave it a directory: true, written down, enforced
by nobody. PARKED below.
