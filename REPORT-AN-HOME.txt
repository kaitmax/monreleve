THE CHOICE TRANSITION (section 1, the operator's main request)
====================================================================
BEFORE a choice: the options are one white card (1 px border via Size.rule, no
shadow) - a vertical list (En Suisse / Domicile / Mission -> En France / Pays tiers;
"Declarer une absence" the tertiary row -> conge/maladie/ferie/autre). Vertical, so
it survives 200 % (R271). The existing SPEC 11.2 / R285 56 dp record BUTTONS were
KEPT (they are already Material 3, already vertical); see ADVISOR DECISIONS for why
I did not swap them for M3 ListItem.

AFTER the tap: the options close and are replaced, IN THE SAME CARD, by one compact
answer line + a "Modifier" TEXT button (a word, so TalkBack reads it):
  - a full day: the kind ("En Suisse") + the sync truth.
  - a half-day pair: BOTH halves - "Matin : Domicile - Apres-midi : En Suisse"
    (R292, never one label); proven by the aujourdhuiHalfDayComplete baseline.
  - sync truth, persistent, never a toast: "Enregistre sur le telephone, en attente
    d'envoi" until synced, then "Enregistre" (aujourdhuiDaySynced baseline).
  - a detected day keeps its provenance line ("Detecte automatiquement, confirme par
    vous") - kept as built (section B), aujourdhuiAutoConfirmed baseline.

MODIFIER reopens the options with the current choice marked; "Annuler" closes them
again WITHOUT writing (it only flips the editing flag; the record callback is the
only writer). Proven on the phone: tap En Suisse -> closed answer; Modifier -> options
with En Suisse FILLED (marked) + Annuler; Annuler -> back to the answer, the year
panel unchanged (no new write).

MOTION - DESIGN-SYSTEM tokens only (ChoiceMotion.kt), never an invented number: the
options fade + the card height shrinks to the answer over Motion.standardMillis
(200 ms), no bounce; reopening is the reverse. Number changes in the year panel
animate over Motion.numbersMillis (300 ms). NO celebration (no checkmark/scale/
confetti) - the confirmation IS the answer appearing (DESIGN-SYSTEM section 2).

REDUCED MOTION: rememberReduceMotion() reads Settings.Global.ANIMATOR_DURATION_SCALE;
0 ("Remove animations") makes every transition snap() - instant, nothing half-drawn.
Driven on the phone with animator_duration_scale 0: the answer rendered cleanly.

ACCESSIBILITY: the answer is a POLITE live region (semantics { liveRegion =
Polite }), so TalkBack announces it when the options close; focus lands on "Modifier"
on that close (FocusRequester, best-effort after the enter settles, and only on a
within-session close so a config change does not steal focus). TalkBack was NOT
enabled in this driven run (it needs the accessibility service toggled + announcement
capture, which the uiautomator harness does not read back); the live-region semantics
are in the code and the "Modifier" is a word, not a pencil, so the announcement is a
real sentence. This is the one H4 sub-item not literally captured - stated plainly.

STATE (R310): the editing-open flag is rememberSaveable (Bundle-backed, like every
other state after AN-STATE). Proven on the phone: reopened the options (Modifier),
rotated to landscape - the options were STILL open and En Suisse STILL marked
(home-07-rotated-editing.png). (The "Annuler" text-probe read ABSENT after rotation
only because it sits below the landscape fold; the screenshot shows the card open.)
