THE MODULE (setup chosen and why - R368 / R136)
--------------------------------------------------------------------------------
Chosen: `com.android.library` + `org.jetbrains.kotlin.multiplatform` with
`androidTarget()`, plus `iosArm64()` and `iosSimulatorArm64()` DECLARED.
NOT the newer `com.android.kotlin.multiplatform.library` plugin.

Evidence/why (R136 conservative, R156 one-risky-thing-at-a-time):
  - It is the long-established, most-documented KMP+Android combination, stable
    across AGP 8.x and Kotlin 2.0.x - no "bleeding edge" risk on top of a new
    module (the AN2/AN5 mature-stable discipline).
  - Its source-set names (androidMain, androidUnitTest) let existing Kotest
    specs move into :shared's Android unit-test set UNCHANGED when needed (R373).
  - `com.android.library` reuses the AGP 8.10.1 already on the classpath - no
    version bump (the hard boundary), where the AGP KMP-library plugin would be a
    second, newer AGP component.
  - PROVEN EMPIRICALLY: the module configures and compiles on Kotlin 2.0.21 /
    AGP 8.10.1. compileCommonMainKotlinMetadata, :shared:testDebugUnitTest,
    ktlintCheck and detekt all ran green; :app:gate is green with :shared wired
    in. No upgrade required.

Wiring: :app depends on it (implementation(project(":shared"))). :app:gate now
also runs :shared:compileCommonMainKotlinMetadata (the platform-free proof),
:shared:testDebugUnitTest, :shared:ktlintCheck, :shared:detekt. The gate's
RAN/SKIPPED printout names them and names the skipped iOS compilations with the
reason (R133/R369). CI runs `./gradlew gate` and gate:clone does not build
Android, so BOTH pick :shared up with NO web/CI edit (the boundary: they call the
Android gate exactly as before).

Two incidental build fixes the move required:
  - detekt in a KMP module scans the JVM src/main layout by default - it reported
    NO-SOURCE (a vacuous pass). Fixed with source.setFrom over the KMP source sets.
  - checkLicences' inputs.files(releaseRuntimeClasspath) could not pick one
    artifact from the KMP android library (many secondary variants, no default).
    Fixed with a lenient artifact view; the licence CHECK reads the dependency
    GRAPH (unaffected) and already excludes project deps, so nothing is weakened.

fixtures/*.json into a Kotlin String constant (object FixtureJson, generated under
