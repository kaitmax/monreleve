R563 - THE LIST (every interface or expect iOS must implement, from the source)
--------------------------------------------------------------------------------
1. HttpTransport (data/remote/Http.kt) - "a thin execute(request) -> response";
   executeForBytes throws by default. TransportException's KDoc: the transport
   owns the translation; cause is kept (R386). Apple API: NSURLSession (ephemeral
   configuration, data task). DONE: NsUrlSessionTransport.
2. TokenStore (auth/TokenStore.kt) - one pair or none; save durable and whole;
   load null before save, and null AND clear when unreadable; clear erases the
   pair only, no network; never logged; not gated on unlock. Apple API: Keychain
   generic password, ONE item, AfterFirstUnlockThisDeviceOnly. DONE:
   KeychainTokenStore.
3. SettingsStore (settings/SettingsStore.kt) - load null until complete; save
   replaces the whole set; absent and null stay null; clear erases all;
   isOnboarded NOT overridden. Apple API: NSUserDefaults, one key, one JSON value.
   DONE: UserDefaultsSettingsStore.
4. DossierCache (data/local/DossierCache.kt) - server bytes verbatim; per-year;
   clear erases every year AND every flag; markStale/isStale shared by every
   instance, flag cleared in the same write as the body. Apple API: a file per
   year under Application Support, excluded from backup (NSURLIsExcludedFromBackupKey).
   DONE: FileDossierCache.
5. The database builder - MonReleveDatabaseConstructor is the ONE expect in
   :shared, and Room's compiler generates its iOS actual (iOS-0 proved that).
   What iOS owes is the builder: Room.databaseBuilder over a path with
   BundledSQLiteDriver. DONE: buildIosDatabase.
6. newMutationId - NOT an expect: LocalEntryRepository takes it as a lambda with
   NO default (a portable default would need kotlin.uuid). Apple API: NSUUID,
   lower-cased. DONE: newIosMutationId.
7. reportUnownedWhileSignedIn - a lambda seam of LocalEntryRepository (R425's
   canary): debug crashes with IllegalStateException, release logs. DONE:
   IosUnownedReporter (Platform.isDebugBinary by default, injectable).
8. The logger - there is NO shared logger interface (Android calls Log.e). DONE:
   IosLogger (NSLog through "%@", scrubbing).
9. The sync trigger - SyncEngine is shared; its trigger (WorkManager on Android)
   is not. DONE without a scheduler: IosSyncTrigger (after a write, and when asked).
10. French formatting (R570) - fr/format is :app-only (java.time / java.text).
    DONE: commonMain fr/text (numbers, calendar-day text) + iosMain instant formats.

R564 - THE TRANSPORT, BYTE FOR BYTE
--------------------------------------------------------------------------------
NsUrlSessionTransport (iosMain). Every NSError becomes TransportException with
an NsErrorException (domain, code, description - never the URL) as its cause;
a non-HTTP answer and an unopenable URL string are TransportException too.
Cancelling the coroutine calls NSURLSessionTask.cancel() from
invokeOnCancellation; CancellationException is never converted.

TIMEOUTS (named, justified in the file): REQUEST 15 s = Android's connect 15 s
and read 15 s (NSURLSession's idle timeout covers both); RESOURCE 120 s - a
ceiling Android lacks, because the platform default is seven days. Ephemeral
session, no cookie storage, no cache, waitsForConnectivity false (offline fails
at once, as on Android).

PROOF ON THE WIRE. .github/scripts/ios-wire-server.py (standard library only,
loopback, started by the workflow before Gradle, refuses to proceed unless it
answers) echoes and records each request. NsUrlSessionTransportWireTest (16
tests) sends the request shapes of AuthWireGoldenTest (magic-link, code,
refresh, callback with t+o+k and a%40b.ch, authenticated POST/PATCH/GET) and of
EntriesWireGoldenTest (envelope, one optional, minimal five, all optionals with
non-ASCII) through the REAL AuthApi and the iOS transport, then reads the
server's record: exact key sets, optionals ABSENT never null, the body bytes
EQUAL to what encodeEntries produced (assertContentEquals), Authorization and
Content-Type headers, methods incl. PATCH. The workflow prints the recording:
RECORDED REQUESTS: 11 (every green run). Also proven: 202/401/422/500 are
responses not exceptions; 256 bytes come back unaltered with Content-Disposition;
a refused connection is TransportException with cause NSURLErrorDomain -1004;
a 1 s timeout is -1001; "not a url" is TransportException.
CANCELLATION: the server records "closed:<path>" when the client closes; the
test asserts (control) it is NOT closed before, the request is open, then
cancelAndJoin makes it closed. The first version read another test's close
event (shared server state) and failed honestly; fixed with a per-request id.

THE RED PLANT. Run 40358530311 on commit 39456da: an extra key

R565 - TOKENS IN THE KEYCHAIN, NEVER SYNCED
--------------------------------------------------------------------------------
KeychainTokenStore: ONE generic-password item (service ch.monreleve.app.session,
account token-pair) holding the JSON pair. save = SecItemUpdate of the value
(atomic per item), SecItemAdd when absent; throws KeychainException(OSStatus) on
failure. load: not-found -> null; undecodable -> clear + null; any OTHER OSStatus
-> null WITHOUT deleting (a locked/unavailable keychain is not evidence the
session is bad). clear = SecItemDelete, not-found is success. Class:
kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly, kSecAttrSynchronizable false
stated on EVERY query.

KeychainQueriesTest reads the REAL CFDictionaries back: accessibility IS
AfterFirstUnlockThisDeviceOnly and is NOT AfterFirstUnlock, WhenUnlocked or
WhenUnlockedThisDeviceOnly; synchronizable false; identity/lookup carry no
accessibility; no access group. Never weakened.

THE LIVE KEYCHAIN - what happened, exactly, in order:
  run 3  under the plugin's `simctl spawn --standalone`: every call returned
         OSStatus -25291 (errSecNotAvailable): a bare process has no securityd.
  run 4  with the simulator BOOTED (workflow step) and the tests run
         non-standalone inside it (Gradle property iosSimulatorDevice ->
         KotlinNativeSimulatorTest standalone=false, device=<udid>): OSStatus
         -34018 (errSecMissingEntitlement), as expected for an unsigned binary.
  run 5  re-signing the binary with `codesign --entitlements` (test-only plist,

  run 7  fixed: GREEN. KeychainTokenStoreContractTest 5/5 against the REAL
         Keychain, including "an unreadable value loads null and is cleared"

scrubLeavesOrdinarySentencesAlone guards against over-scrubbing the canary text.
