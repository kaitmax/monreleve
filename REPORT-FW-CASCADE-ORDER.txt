R1011. THE FIX
--------------
THE MECHANISM: the stack rules carry the card's own selector,
`> :not(:first-child)` instead of `> * + *`.
- CalculatorForm.module.scss:189-192 (main) -> 197-200:
  `.revealed > :not(:first-child), .advanced > :not(:first-child)
  { margin-top: var(--space-5); }`
- comparateur.module.scss:88-90 (main) -> 94-96:
  `.form > :not(:first-child) { margin-top: var(--space-6); }`
- Plus the comment above each saying why. No other line changes: two
  files, +18/-4, all SCSS. Tokens unchanged (the same --space-5 and
  --space-6); no raw value.
WHY IT HOLDS BY CONSTRUCTION: `X > :not(:first-child)` selects exactly
the elements `X > * + *` selects (an element is not the first child iff
it has an element sibling before it) at (0,2,0) instead of (0,1,0). Every
lib/ui/react rule that claims a margin on a component's root is a single
class, (0,1,0) (census above), so specificity decides each pair and the
chunk order cannot.
WHY THIS ONE, the smallest that holds:
- It is the file's own precedent. CalculatorForm.module.scss:95-98 already
  made `.card`'s stack `:not(:first-child)` "so a child that zeroes its own
  margin (.group, and SegmentedChoice's fieldset) still gets the gap";
  :189-190 is the site that fix missed (R267's shape).
- It changes no shared component. SegmentedChoice and SegmentedButtons
  are also rendered by the workbench and the island harness, and their
  reset stays exactly as it is.
- It changes no layout mode. A flex column with `gap` (the design file's
  way) would stretch the comparator's inline-flex submit button to the
  full width and stop sibling margins collapsing in its form, which would
  move comparator baselines (reasoned, not run); and the card's own comment (CalculatorForm.module.scss:86-90)
  already refuses flex for the fieldset legend's sake.
- The other example, narrowing the fieldset resets to `margin-inline: 0`
  (the comparator's own .persons does that), also holds, but it edits two
  shared components for a gap the containers own. One mechanism, not both.
NO OTHER LOOK MOVES, checked before the run against every direct child the
heavier selector newly beats: .advanced's FieldGroups and .revealed's
FieldGroups claim no margin; .form's other children are FieldGroup (none),
div.joint (none), fieldset.persons (margin-left/right only),
button.submit (none), and the first child (h2) is not selected. The
comparator's three toggles already had the 24 px gap in the container
(P2: the stack was later), so they keep it.
