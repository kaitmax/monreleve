ITEM 3 (R436) - THE GLYPHS GROW WITH THE TEXT (PARK-I5 CLOSED)
--------------------------------------------------------------------------------
COMMIT c4d8dce.

WHICH, AND WHY. The `icon` SIZE TOKEN TIMES THE FONT SCALE -
Size.icon * LocalDensity.current.fontScale - not an sp-derived size.

On this platform's linear font scaling `20.sp.toDp()` computes the same number,
so the difference is NOT arithmetic. An sp size spells the figure 20 a SECOND
TIME beside the token that already holds it, and that second figure is free to
drift from Size.icon the day the token moves. Size.icon * fontScale has no
second figure to disagree with: it IS the token, scaled by exactly the
multiplier the words beside it are taking (R206/R181). It is also the honest
reading of PARK-I5, which recorded "R430 names the `icon` size token (20), so 20
dp fixed is what was built" - the token is still what is named, it is simply no
longer fixed.

SCOPED TO THE ANSWER LINE. Every other Icon keeps Material3's fixed default, as
AN-ANSWER-ICON left them; retrofitting them is a visual change to screens this
task was not asked to touch.

THE CHANGE IS UNFORCED AT DEFAULT SCALE, AND THAT WAS CHECKED RATHER THAN

rows PENDING, which is where they already were, and the dialog then names them.

     clause - and auth/SessionManager.signOut carries the same shape for the

     still green.
  3. Therefore a cancellation DURING THE SEND cancels a coroutine that has
     revoked nothing and cleared nothing: there is no partial sign-out to leave
     behind, and nothing in ITEM 6 can skip the wipe, because ITEM 6 happens
     entirely before the wipe can start.
