1. A SIX-DIGIT CODE ALONGSIDE THE LINK (SERVER, THEN APP)
====================================================================
WHY. The sign-in link can open the app only once monreleve.ch exists
and its App Link is verified; until then it opens a browser and the
sign-in fails. And people often read email on another device. A code
in the same email works from anywhere and does not depend on the
domain. It is the most important part of this task.

THE SERVER, test-first:
  - The same email carries the link AND a 6-digit code, both tied to
    the same single-use sign-in request and expiring together. Using
    either one consumes both.
  - The code is stored HASHED, never in clear, and compared in constant
    time.
  - A limit on wrong attempts per request - after it, the request is
    dead and the person asks for a new one - plus the existing rate
    limits per address and per network source. State the numbers you
    choose and why; six digits are safe ONLY with an attempt limit.
  - A new endpoint to exchange email + code for the same session the
    link gives - the same tokens, the same rotation and replay rules
    (R193, R210). The response for an address that does not exist is
    the same as for a wrong code: no enumeration (FW22).
  - Each refusal named (R198): wrong code, expired, too many attempts,
    rate-limited.
  - The email template shows the code clearly, in French, beside the
    link. In tests and development, read it from the fake outbox.
  - docs/api-v1.md documents the endpoint; the document-and-schema
    drift test covers it.

THE APP:
  - THE EMAIL SCREEN: one field, marked as an email address for
    Android's autofill, so the phone suggests the owner's address
    (verify the suggestion appears on the S9). THE APP NEVER STORES THE
    LAST EMAIL: on a shared or handed-on phone it would be a trace of
    the previous person (R295). The consent line links the CGU and the
    privacy policy.
  - THE CODE SCREEN: six boxes; each digit moves to the next box;
    pasting a six-digit code fills all six; the sixth digit submits.
    The address typed is shown, with "Modifier" back to the email
    screen. "Ouvrir ma messagerie" opens the email app. Resending waits
    out a visible countdown. Each refusal has its own French message;
    wrong-code messages say how to recover, never just "erreur".
  - The App Link callback keeps working exactly as before.
