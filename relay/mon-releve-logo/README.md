# Mon Relevé — logo kit: the rail

The mark is the threshold rail: a track filled to about a third, stopping
short of the tick at 40 %. It shows the product's answer — where you stand
against the threshold — in one shape.

**Brand colour:** Deep Alpine Blue `#173B63` (DESIGN-SYSTEM.md).
**Wordmark:** "Mon" in Inter Regular, "Relevé" in Inter SemiBold, tracking −1 %.
The wordmark in every file is converted to outlines, so it renders the same
without Inter installed. Inter is under the SIL Open Font License, which
permits this use.

### Android

`mipmap-anydpi-v26/ic_launcher.xml` declares background, foreground and
**monochrome** layers, so Android 13+ can show it as a themed icon. minSdk is
26, which supports adaptive icons natively, so no legacy PNG mipmaps are
needed. The foreground sits inside the 66 dp safe zone, so no launcher shape
crops it. The manifest's `android:icon` and `android:roundIcon` should point
at `@mipmap/ic_launcher` and `@mipmap/ic_launcher_round`.

## Rules

- **The fill never reaches or crosses the tick.** A mark past the threshold
  reads as a warning.
- **Below 32 px, use the small version** — its bars are thicker so it stays
  legible.
- **Clear space:** keep at least a quarter of the mark's width empty around
  the logo.
- **Never:** recolour the tick on its own, add a gradient or shadow, rotate
  it, put it inside a seal, badge or shield (the product never claims
  "certifié"), set the wordmark in another typeface, or drop the accent on
  "Relevé".
- **Colour:** brand blue, white, or black only.
