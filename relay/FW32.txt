CONTEXT
====================================================================
FW32 ONLY: repair the verifier. It ships no product code.

TWO DEFECTS, BOTH IN THE THING THIS PROJECT TRUSTS MOST.

  THE LEAK, root-caused in AN1 and not yet fixed:
  web/scripts/gate-clone.mjs calls process.exit(1) from inside its
  own try block on every step failure (line 399, and 357/510 for two
  other paths), while the clone's removal sits in that try's finally
  (line 557). process.exit does not unwind to a pending finally, so
  EVERY FAILED RUN LEAKS ITS CLONE - not only killed ones, which is
  what CLAUDE.md's "periodic manual cleanup" note assumes. Nine
  leaked clones filled this machine to zero bytes; it recurred inside
  the same session after being cleaned.

  THE SILENCE: on a fresh clone of main, pnpm test prints thirteen
  benign axe-core canvas warnings and then NOTHING - no banner, no
  file list, no summary - and exits 0. The same suite in the working
  tree passes 163 files and 2901 tests with a printed summary. So it
  is clone-specific. gate:clone's R133 check refused to call the
  silence a pass, which is the only reason anybody knows.

WHY THIS IS ITS OWN TASK. gate:clone is the ONLY thing standing
between this project and "it worked on my machine" while CI is off
(R199, R248, R257). A verifier that leaks 1.7 GB per failure and
cannot run the web suite is not a verifier. Everything downstream -
AN2's engine port, FW31's production write, the whole Android series
- rests on it.

Read: web/scripts/gate-clone.mjs IN FULL, REPORT-AN1.txt,
docs/PHASE-4-GUIDE.md section 11, CLAUDE.md's cleanup note.
