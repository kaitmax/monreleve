====================================================================
HOW TO RUN EACH TASK: A FRESH AGENT PER TASK
====================================================================
Launch EACH TASK AS ITS OWN AGENT, with a fresh context, giving it the
task's prompt file to read from disk and execute in full. Wait for it
to finish before launching the next. Do not run two at once - they
share the phone and the theme.

A fresh agent per task is what makes "do not stop" possible: one
session carrying four phone-heavy tasks would run out of context
partway, and AN-NEXT alone used more than half a million tokens. This
orchestrating session stays light: it launches, waits, checks, and
launches again.

If this session cannot launch agents, run the tasks in sequence itself,
and stop the chain cleanly the moment the context degrades - stopping
after two clean tasks is a good outcome; four rushed ones are not.

BETWEEN TASKS - THE HANDOVER CHECK
====================================================================
Before launching the next task, all of these must hold, and are
recorded in REPORT-CHAIN-ANDROID.txt:
  - the finished task's report is committed and pushed, and it ended
    DONE - or ended cleanly at a pushed point with what remains named;
  - git status is clean and local main equals origin/main - a task that
    worked on a branch (R300) has merged it, after its own gate:clone;
  - pnpm gate:clone and :app:gate are green on the merged HEAD;
  - no orphaned emulator, adb server, container or port (R179), and the
    phone's settings are back to normal: automatic time and timezone
    on, screen timeout normal, "Don't keep activities" off, animations
    on, font scale 1.0;
  - nothing in the report is marked as blocking the next task.
IF A CHECK FAILS, STOP THE CHAIN. Write REPORT-CHAIN-ANDROID.txt saying
which check, after which task, and why; commit, push, end. Do not
launch the next task on a broken base.

A TASK THAT ENDS WITH "NO PROGRESS" OR A HARD BOUNDARY stops the chain
too: the next task would build on something unfinished.
