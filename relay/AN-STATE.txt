R308 (new). LINT'S NewApi CHECK GOES INTO THE GATE PERMANENTLY. The
    crash DEVICE-LOOP fixed was an API 34 method called on an API 29
    phone, and the guard added for it scans for that one method - R211's

R309 (new). WALKTHROUGHS INCLUDE AN EMULATOR AT THE OLDEST API THE APP
    CLAIMS. minSdk is 26; every walkthrough so far ran on a much newer
    image, which is why an API 34 call reached a phone. Create an
    API 26 image and run this task's matrix on it as well as on the
    physical phone.

R310 (new, and it is this task). THE PERSON STAYS WHERE THEY WERE.
    After any of these, the app shows the same screen, the same tab,
    the same open sheet or dialog, and the same half-entered text:
      - ROTATION;
      - A TEXT-SIZE CHANGE - R16 requires 200 percent, and changing the
        text size while the app is open rebuilds it exactly as
        rotation does;
      - A DARK-MODE SWITCH - the app ships light-only, but the system
        switch still rebuilds the screen;
      - A BACKGROUND KILL - the system ending the process while the app
        is in the background, and rebuilding it when the person
        returns. Surviving this is harder than surviving rotation:
        state held only in memory, even in a ViewModel, does not
        survive it. Saved state does.
    Checked on every screen that holds state - never on the start
    screen alone.

WHAT A FIX IS NOT, whatever an advisor says:
  - LOCKING THE APP TO PORTRAIT. Text size, dark mode and background
    kills still rebuild it; it fails people who use a phone in
    landscape; and recent Android versions ignore orientation locks
    on large screens.
  - android:configChanges TO STOP ANDROID REBUILDING ON ROTATION. It
    hides rotation and nothing else.
  - weakening, skipping or deleting a test, or catching and ignoring
    an error.

R291's LESSON STANDS. Moving the wiring into a plain Kotlin object made
    it testable, and that is not undone here. If that object is created
    with the activity, everything it holds dies with each rebuild: move
    the STATE somewhere that outlives the screen, keep the WIRING
    testable.

CARRIED: R133 a check must be able to fail. R180 verify a plant
