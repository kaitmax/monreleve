R324 - A FIX IS CLASSIFIED ONLY IF IT IS PRECISE ENOUGH
--------------------------------------------------------------------
THE RULE (BorderPolygon.classify, detection/): a fix classifies to a side ONLY
IF its accuracy radius is smaller than its distance to the border; otherwise it
counts as BUFFER ("not sure"). Effectively the strip widens to max(150 m,
accuracy). A fix with no stated accuracy is treated as imprecise (fail-closed,
Double.MAX_VALUE in LiveLocation.accuracyMetersOrUnresolvable). The engines are
untouched (D16): this lives in detection/, not calc/.

TESTS (test-first; the RED shown):
  - ClassificationTest (JVM): three cases DERIVED from the real polygon (R171,
    no hand-typed metre figure) - a near-but-classifiable inside point is found
    by walking inward from a border vertex until distance-to-edge is 200-1500 m:
      * coarse fix near the border  -> BUFFER (not sure)
      * same coarse radius far away (Bern) -> classifies INSIDE
      * precise fix near the border -> classifies INSIDE
      * a fix with no stated accuracy -> BUFFER (imprecise)

reword says so, naming "les reseaux Wi-Fi et cellulaires ... selon les reglages
