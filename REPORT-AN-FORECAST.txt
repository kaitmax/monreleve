    Room IS the restore store.

THE FORECAST (the imagined-days function, the fixture, each case)

NEW date logic this session (section 2's "past days left unrecorded"):
  dossier/Forecast.kt :: unrecordedPastWorkdays(recordedDays, today,
    taxYear, activityStartIso) - the count of weekdays from the start of
    the year (or the activity start, whichever is later) through today
    with no recorded entry. Pure (today is the only clock, R28), weekdays

    figure, so it is bound by a direct JVM test (ForecastUnrecordedTest,
    four cases) rather than the shared fixture, which binds the RATE
    contract. The screen shows it in words only when it is greater than zero.
