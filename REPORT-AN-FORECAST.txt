THE FORECAST (the imagined-days function, the fixture, each case) - DONE
====================================================================
dossier/Forecast.kt (pure, no clock, no store, R28/R340/R281):
  imaginedEntriesToYearEnd(rhythm: Map<DayOfWeek,EntryKind>, today, taxYear)
    -> List<AggregatableEntry>. One FULL row per weekday (Mon-Fri) the
    rhythm assigns, from the day AFTER today to 31 December. Today is
    never imagined. Weekends never count. Holidays/leave NOT deducted
    (overstates telework, so it warns early not late - R340).
  forecastResults(user, recorded, rhythm, today, taxYear) ->
    ForecastResults(current, projected, imagined). THE ONE PLACE the
    engine is run for a forecast: current = engine on the record alone;
    projected = engine on record + imagined; both through toTeleworkInput
    (the shared aggregation, R281) and calculateTelework. No arithmetic
    in a component (FW12's defect). Returns null only if the engine
    rejects the settings (the "complete your settings / set a rhythm"
    case).

fixtures/forecast-cases.json (CREATED - FW-FORECAST will CONSUME it, not
fork it; R281). commonUser GE/100/SIMPLIFIED240/DAY, taxYear 2026. Each
case: a rhythm, a fixed "today", the recorded days, and the expected
imagined-day counts + the engine's declarable rates. Five cases:
  rythme-mardi-jeudi-depuis-octobre   today 2026-10-09, Domicile Tue+Thu,
      Suisse otherwise, 0 recorded -> 59 imagined working days, 24
      telework, projection 10.00%. This REPRODUCES THE DESIGN'S OWN
      numbers: the design reference says "59 jours ouvres jusqu'au 31
      decembre" and "24 remaining Tuesdays and Thursdays".
  rythme-complet-fin-dannee           today 2026-12-24, all Domicile, 0
      recorded -> 5 imagined, 5 telework, projection 2.08%.
  enregistre-plus-imagine             today 2026-12-24, all Domicile, 3
      recorded HOME -> current 1.25%, projection 3.33% (record + rhythm).
  les-jours-suisses-ne-bougent-pas-le-taux  today 2026-12-24, all Suisse,
      10 recorded HOME -> 5 imagined working days, 0 telework, projection
      4.16% = current 4.16% (a Suisse rhythm does not move the rate).
  rythme-partiel-mardi-jeudi          today 2026-12-24, only Tue+Thu set
      -> 2 imagined, 2 telework, projection 0.83% (null days imagine
      nothing).
  All rates hand-verified as truncate(teleworkDays / 240 x 100, 2); the
  59/24 counts hand-verified against the 2026 calendar.
