R559 - A SENT DAY MAKES THE CACHE STALE (the interface change and its contract)
================================================================================
DossierCache (:shared commonMain) gains two abstract methods, with no default bodies:
    fun markStale(year: Int)
    fun isStale(year: Int): Boolean
Contract, as written in the KDoc for iOS:
  - markStale sets a per-year flag and never touches the body. load returns the same
    bytes before and after. Marking a year with no copy is allowed, must not throw and
    must not create a body.
  - isStale is true exactly when markStale was called for that year after its last
    save (or after the last clear, or ever, if the year was never saved). Years are
    independent.
  - save clears that year's flag in the same write as the body. A reader never sees the
    new body still flagged, or the old body unflagged.
  - clear erases every flag along with every body.
  - The flag is as durable as the body and is shared by every instance in the process.
    The sync worker and the screen hold different instances, so an in-memory field on
    one instance does not meet the contract.
  - The flag is not part of the body: a copy cached before this change reads back
    unchanged, and reads as not stale.
Android: SharedPrefsDossierCache stores the flag as its own key, "stale.<year>", in
monreleve.dossier. "dossier.<year>" and its raw value are unchanged, and
OnDeviceFormatGoldenTest passes unedited. save is putString + remove in one edit.
SyncEngine takes `dossierCache: DossierCache` as a REQUIRED parameter. On HTTP 200 it
marks every distinct year of the batch, before the reconcile writes SYNCED rows, so a
screen reacting to rows leaving pending already sees the year stale. It marks even when
the 200 body will not parse, because the server wrote. A refused batch (400/409/413), a
transport fault, an empty queue or no session marks nothing. An isolated batch marks
only the year of the day the server accepted. buildSyncEngine passes
SharedPrefsDossierCache(context).
Tests, SyncEngineTest (+4):
  - anAcceptedBatchMarksEveryYearItTouchedStale: 2026 and 2027 marked, 2025 not;
  - aDrainThatSendsNothingMarksNothing;
  - anIsolatedBatchMarksOnlyTheYearOfTheDayTheServerAccepted: [2027];
  - theYearIsMarkedBeforeItsRowsLeavePending: [PENDING] at the moment of the mark.
