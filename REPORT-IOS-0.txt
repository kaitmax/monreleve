was: kotlinx-datetime 0.6.1 reads zone rules from a fixed path -
/usr/share/zoneinfo.default on a simulator (core/darwinSimulator,
defaultTzdbPath) - and on the runner that path reports
    zoneinfo.default +VERSION: 2024a

    /var/db/timezone/zoneinfo +VERSION: 2026c.

real iPhone reads /var/db/timezone/zoneinfo (core/darwinDevices) - the OS's
current tzdata - so the device question R472 item 2 raised is still iOS-1's
(PARK-N3).

   TokenStore      (auth/TokenStore.kt) -> Keychain Services (SecItemAdd /

B. platform code with no shared interface yet
   the database builder -> Room.databaseBuilder<MonReleveDatabase>(name = a path
                   under NSDocumentDirectory) - with MonReleveDatabaseConstructor
                   now PROVEN generated for iOS. NEW, MISSED BY R455/R472:
                   on every non-Android platform Room needs a SQLiteDriver
                   (setDriver), and the catalog has none -
                   androidx.sqlite:sqlite-bundled (BundledSQLiteDriver) or
                   sqlite-framework (NativeSQLiteDriver, the system libsqlite3).
                   That is a NEW DEPENDENCY: Ask first (QUESTION Q2).
   the sync trigger -> BGTaskScheduler (BGProcessingTaskRequest with
                   requiresNetworkConnectivity; Settled -> done, Retryable ->
                   reschedule, Unauthenticated -> done, NOT a retry).
   the account tag -> SHA-256 via CommonCrypto CC_SHA256 (reachable from
                   Kotlin/Native as platform.CoreCrypto) or CryptoKit from
                   Swift; AccountStore; the UNOWNED rule.
   the pending sign-in store -> Keychain (a credential in this threat model).
